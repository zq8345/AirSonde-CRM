## 0. 我们以什么身份卖

AirSonde = 依托中国供应链（供应商：icanow，Joe 朋友的店）做**空气质量检测仪的 OEM/ODM/批发供应**，
面向欧美 B2B。核心业态是**贴牌**：客户的牌、我们的货。站与 CRM 都是获客工具，非自有品牌零售。

## 1. 目标客户分层（按优先级）

**T1 · IAQ 品牌方 / 想上自有品牌的渠道商**
已在卖或想推自有品牌空气检测产品的公司。ODM 贴牌是我们的主业态——单量大、复购稳、
关系粘性强。判据信号：产品线里有 IAQ/环境监测品类、提到 private label/OEM/own brand、
有品牌但无自有工厂迹象。

**T2 · 楼宇自控 / 智能楼宇 / HVAC 系统集成商与服务商**
把 IAQ 传感与监测仪随新风/空调/BMS 项目打包交付的公司。项目制、价格不透明、毛利好，
且常要 Modbus/BACnet/API 对接等定制——正是 ODM 的长项（⚠️ 对接能力本身待工厂确认，见 §5）。
判据信号：BMS/building automation/HVAC controls/ventilation 业务 + 项目案例页。

**T3 · 进口商 / 区域分销商 / 批发商**
美/加/欧/英/澳的暖通、电工电料、环境仪器、安防楼控品类分销商。走量、复购稳，
是天然下游。判据信号：distributor/wholesaler/importer 自述 + 多品牌产品目录。

**次要（低成本可得才做，不作主力）**
学校/办公楼宇 IAQ 合规服务商、室内环境检测/治理服务公司、职业健康与实验室设备商。

**为什么是这个顺序**：继承上游验证过的原则——优先"毛利好、靠关系与本地化、能走量复购"，
刻意避开纯比价铺货红海。T1 粘性最强（换贴牌供应商成本高），T2 单值最高（项目制），T3 量最大。

## 2. 打分判据（骨架继承上游，域内容为本稿）

- **唯一正向判据**：官网能否看出它在「卖」「集成/安装」或「贴牌运营」空气质量/环境监测
  （或 HVAC/新风/楼宇自控/环境仪器）**实体硬件**。看得出 → 合格 60-95，不看体量
  （三人暖通安装队与大型楼控集成商同权）。
- **服务商纠偏**：HVAC 公司/楼宇管理方/检测治理服务商完全可能同时采购或转售硬件——
  "是服务商/是大公司"不作压低判据。
- **信息不全 ≠ 不合格**：看不出碰不碰硬件 → 40-55 中间分待人工复核，绝不反射压 30。
  （误杀一个真买家比多发一封给纯服务商代价大得多，两类错不对称。）
- **一票压低 ≤30**（仅限明确命中）：纯内容/评测/博客站；通篇纯服务零硬件痕迹（慎判）；
  中国铺货同行/亚马逊同质低价卖家；自有工厂的成熟检测仪大牌（竞品非买家）；非真实经营实体。

## 3. 排除项（硬边界）

1. 中国主体铺货卖家（@163/@qq 邮箱、+86、中文站/.cn、跨品类白牌铺货、无本地地址）——价格战压毛利。
2. 纯内容站——"满篇 air quality"最会骗分，判据是"自己不卖也不装任何东西"。
3. 成熟大牌（Airthings/Awair/Aranet 这个量级）——竞品，不是 ODM 买家。
4. 制裁/雷区市场：沿用上游 BLACKLIST（含 cu/ir 硬排除；ir/ye 故意不入表，要加由总工显式决定）。
5. **地理主战场：美/加/英/欧/澳新**。上游 COUNTRIES 全量表保留作 UI 真源，
   搜索面收窄到主战场是 settings 配置动作，画像拍板后一并做（待 Joe 圈定名单）。
