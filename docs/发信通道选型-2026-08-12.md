# 发信通道选型（清单第 1 项 · 2026-08-12 · CRM 窗）

> ⛔ 本文档只做选型，**不开任何发信能力**。C1 锁死态不变（无 key = fail-closed）。
> 结论一句话：**推荐沿用 Resend（上游现役路径，代码零改动），Lark 只做收信端；
> 前置硬条件是发信开通时必须同时开一个公开 host（webhook + 退订链接）。**

## 0. 现状事实（全部已实测，2026-08-12）

**DNS（我 nslookup 复验，与总工实测一致）：**
- MX = mx1/mx2/mx3.larksuite.com（Lark 收信）
- SPF = `v=spf1 +include:spf.onlarksuite.com -all` ← 注意是 **-all 硬拒**，且只含 Lark
- DMARC = `v=DMARC1; p=none; rua=mailto:sales@airsonde.net`（预热起步的正确姿势，收紧节奏见预热计划）
- DKIM = Lark 已启用（据总工）

**代码（本仓 grep）：**
- 发信唯一出口 = `send.ts` POST `api.resend.com/emails`（Bearer RESEND_API_KEY）
- `webhook.ts` 消费 Resend 四类事件：bounced→标退 / complained→自动进压制名单 / opened / clicked（区分退订链接与真实链接）
- 打开/点击追踪列（sprint1）被 4 个文件消费：熔断器、趁热跟进（engaged）、看板
- 收信 = `imap.ts` 经 `cloudflare:sockets` connect() 连 Lark IMAP 993 —— **本仓已有 Workers 裸 TCP 的生产先例**

## 2. 推荐

**A（Resend 发）+ Lark 只做收（sales@airsonde.net IMAP）= 与上游完全同构。**

- 13k 行里发信的节流/熔断/压制/审批/回复匹配全部围着 Resend 事件模型长的——换通道等于把 C1"一行都不从零写"的原则反着来。
- B 的真实位置：**人工商务往来**（Joe 手写信）走 Lark 客户端本来就该这样；机器通道不碰它。
- C 的真实位置：将来产品询盘**确认信**这类事务信可以考虑迁过去省钱，非本阶段。

## 3. ⚠️ 前置架构条件（发信单开工时必须一并做，C1 故意关掉了）

Resend webhook 回调 + 邮件里的退订链接都要**公开可达的 host**，而现在：
- `workers_dev: false`（C1 锁死决定）
- API_HOST/PUBLIC_API_URL 未配（#53 公开分支不激活）
- crm.airsonde.com 在 Access 门后（挡 webhook = 收不到退信/投诉 = 合规瞎飞）

开通方案二选一（届时定）：
1. 重开 workers.dev 路由（上游老做法，APP_URL 指它）
2. 直接上公开正门 `api.airsonde.com`（上游 #53 成熟做法：custom_domain + 只放 /u·/api/webhooks/*·/catalog·/api/inbound，其余 404；**绝不给它配 Access**）
   —— 推荐 2，一步到位，代码已支持（配 API_HOST/PUBLIC_API_URL 即激活）。

## 4. Joe 要做的事（全部 Joe-gated，按顺序）

1. **Resend 账号**：⚠️ 建议**独立新账号**（勿复用 Wanew 的）——Resend 按账号管信誉，独立账号 = Wanew/AirSonde 互不连坐；代价是免费额度分开、多一套登录。要共用也能跑，风险自担，Joe 拍板。
2. Resend 后台 Add Domain → `airsonde.net`（默认 send 子域）→ 把给出的三条记录加进 Cloudflare DNS（airsonde.net zone）→ Verify。
3. Resend 后台建 webhook（指向届时的公开 host `/api/webhooks/resend`），拿 `whsec_` 签名密钥。
4. `wrangler secret put RESEND_API_KEY` / `RESEND_WEBHOOK_SECRET`（由执行窗配合，key 不进对话）。
5. 定发件人：**推荐 `sales@airsonde.net`**（信箱已存在，From=收信箱，客户直接回信进 Lark IMAP，零转发配置）；对应 `LARK_IMAP_USER=sales@airsonde.net` + `LARK_IMAP_PASS`（Lark 邮箱专用密码）。
6. 公开正门若走 api.airsonde.com：确认该子域**不建 Access 应用**（上游 #53 红线原话照抄）。
